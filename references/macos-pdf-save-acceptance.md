# macOS PDF 查看器自动保存验收

日期：2026-09-13。环境：macOS 27.0、日常已登录 Google Chrome 152.0.7977.83、英文系统界面，Apple Events 默认后端。真实调用来自本机 Codex；其他 Harness、中文系统界面及 Windows 原生窗口未据此验收。

实现使用 Apple Events、JXA 和 System Events 辅助功能接口。无需新增 Python 第三方运行依赖、Node.js 或 Chrome 扩展；原生界面操作另需为实际运行 Agent 的应用授予辅助功能及相应自动化权限，见 [安装说明](install-macos.md)。

## 本地与线上测试的区别

最初地址栏的 `file:///…/papers/PMID-31647093.pdf` 是上一轮用户保存后归档的本地文件。以它打开查看器、自动另存到中文及空格路径，只能证明界面操作和文件保存，不作为新的出版社下载证据。

随后通过统一 CLI 在新目录下载 PMID `31647093`，源文献为 *Within family Mendelian randomization studies*，DOI `10.1093/hmg/ddz204`。Oxford 出现验证后，程序保持当前篇；收到用户“已完成验证”的实际回复才恢复。

真实正文入口为：

[Oxford 正文 PDF](https://academic.oup.com/hmg/article-pdf/28/R2/R170/31081074/ddz204.pdf)

该入口实际跳转到 `watermark02.silverchair.com/ddz204.pdf` 并带临时参数。首次原生预检查因地址不完全相同而暂停，尚未点击下载；补齐该已观察到的重定向规则并收到用户“继续自动保存”回复后，从当前线上 PDF 继续，没有重新打开文章。

## 结果

| 检查 | 本次结果 |
|---|---|
| 内置 PDF 查看器 | 识别“Download”、页码、侧栏和打印控件；排除共用 `save` 控件 ID 的 Google Drive 按钮 |
| 原生保存 | 自动点击下载、填文件名、打开并识别“前往文件夹”子窗口、设定中文及空格路径、核对目录后点击 Save；无需用户手动保存 |
| 归档文件 | 638,027 字节，10 页；pypdf 首页题名和第一作者核验通过 |
| 重跑原命令 | `cached: true`，文件仍为 1 份，路径及 SHA-256 不变 |
| 最终原生组件复验 | 从同一线上 PDF 再存入独立测试目录；无界面错误，得到相同 SHA-256 |
| 临时状态 | 复验前关闭 Chrome 增强辅助功能树，程序按需开启，结束后恢复；日常 Chrome 保留 |

本次线上文件 SHA-256：`908192738c42d0dc4bf0f3dc9e95662e250db310f13678346cd3c18bdcd4e927`。它与早先手动保存件的 SHA-256 不同，不能把两次下载说成字节完全相同；本次两份自动保存件及续跑结果相同，正文身份核验通过。

实现过程中还观察到：点击 Save 后，Chrome 的辅助功能窗口列表可能短暂变化。最终实现完成点击后不再发送界面输入，通过文件稳定性、格式、正文身份及归档核验确认完成，不以保存窗口消失作为下载成功证据。Chrome 自带 AppleScript `save tab` 在本地试验中只保存了 HTML 包装页，未采用。

## 离线回归与边界

`python3 -B -X utf8 -m unittest discover -s tests -v`：118 项，117 项通过，1 项独立 Chrome 测试按默认配置跳过。本次未重新运行该可选传输测试；它也不能替代原生窗口、扩展或机构权限验收。

新增覆盖：错误窗口/标签/地址、HTML 页面、已有弹窗、Google Drive 和多按钮歧义、错误目录与文件名、拒绝覆盖对话框、辅助功能权限失败、保存结果不明时不重复点击、已知点击前失败需确认后重试、签名地址参数不留存、无文件不能成功、HTML 伪装 PDF、未完成文件、恢复归档与同名保护，以及 PubMed 身份核验保留。Windows 和扩展后端不会调用原生保存组件。

当前限定 Chrome 内置 PDF 查看器和可明确识别的标准保存窗口。除了原 PDF 地址，仅接纳已实测的 Oxford → Silverchair 同名 PDF 重定向；其他地址变化、非标准窗口或用户切换标签时交接人工。中文控件文字只有离线覆盖。用户完成验证码、登录和程序返回的人工暂停仍须实际回复；不自动绕过。

本地证据位于忽略目录 `tmp/macos-native-save/`，包括本地文件试验、线上 CLI 结果、原生复验、续跑及离线测试日志。下载正文、浏览器状态和临时访问参数不进入发行包。
