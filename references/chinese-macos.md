# 知网中文库（站点细节）

> 新版优先使用[统一命令行](cli.md)。下列 `.sh` 示例仅为 macOS 兼容入口；Windows 使用对应的统一命令。站点选择器与匹配规则两平台共用，退出状态以新版 CLI 文档为准。

先遵循入口的对话流程与共用约束。中文期刊、博硕、会议全文走本页；外文 DOI 详情页不走中文下载。

## 检索与只做目录

中文题名清单直接走 `download cnki` / `batch`。只有研究方向时使用统一入口检索，程序会切回中文库；多主题 AND 用 `--expert` 指明完整专业检索式：

```text
python3 scripts/academic.py --json search cnki "项目式学习" results.json --pages 2
python3 scripts/academic.py --json search cnki "SU='孟德尔随机化' AND SU='近视'" results.json --expert
```

结果含命中总数、本次提取数、题名、行内原文及真实详情链接；逐页保存检查点，同参数重跑可复用已完成结果。当前使用知网提交检索后的默认排序，不能把它标作被引排序。无需导入内部 Python 模块或自行编排检索脚本。

只做目录时执行 `scripts/cnki_rows.js` 取题名、结果行文本与 `href`，每条用摘要页链接生成目录；不要运行会触发下载的 `cnki_dl.sh`。中文结果行不能直接当作完整的外文元数据，按已抽字段整理，缺失项不编造。

## 单篇下载

```bash
SK="<skill-dir>/scripts"
"$SK/cnki_dl.sh" "检索题名" "第一作者" "/目标/文件夹"
# 多字段或多主题：
"$SK/cnki_dl.sh" --expert "SU='学习进阶' AND SU='化学'" "题名" "第一作者" "/目标/文件夹"
# 同名作者收窄到机构：
"$SK/cnki_dl.sh" --affiliation "机构" "题名" "第一作者" "/目标/文件夹"
```

所有下载条目都必须给第一作者，否则在打开浏览器前退出 64。题名归一化精确优先；包含匹配仅在给了作者且本页唯一时采纳，多候选不会取首条。短题名、相似题名尤其要核对 `SEARCH` 返回的题名作者。

流程：题名字段 TI / 专业检索 → 点回中文 → 等结果稳定 → 匹配（默认最多 3 页）→ 等详情页并核对题名作者 → 快照下载目录 → PDF 优先、无则 CAJ → 检查下载及收费/验证码 → 核验后归档。macOS Apple Events 保持页内 location.href；扩展后端通过 Playwright 点击唯一可见的下载按钮，保留其点击事件与 referrer，不能改成直接 open/curl 下载地址。

扩展后端将下载事件对应文件暂存在本篇检查点旁，核对文件名中的作者及格式后归档。没有下载事件时仍检查 Chrome 实际下载目录；两处都没有可核验文件则暂停，不再自动点第二次。检查点保存按钮信息、下载事件与错误原因，复测时可据此定位；其中可能含机构跳转参数，分享前须脱敏。中断留下的 `received.part` 不会被当成已完成文件，需核对传输或人工保存后恢复。

`--pages N` 设置匹配页数，0 不翻页。页面按就绪条件继续并保留超时；订单生成和文件等待没有被压成短固定 sleep。无关下载不阻塞当前论文。同名目标保留原文件并为新文件加序号。

| 退出码 | 含义 | 后续 |
|---|---|---|
| 0 | 已归档，输出 `ARCHIVED:` 完整路径 | 核验文件、记录路径 |
| 1 | 无结果、歧义或详情身份不符 | 看诊断；不要放宽为首条匹配 |
| 2 | 验证码、登录验证或待人工保存 | 用户完成后先检查已落盘文件 |
| 3 | 详情页无 PDF/CAJ 下载链接 | 转题录 |
| 4 | 无唯一稳定文件或归档核验失败 | 核对下载目录与作者 |
| 5 | 收费页/无机构权限 | 转题录并记录原因 |
| 6 | 用户明确跳过 | 保留用户决定 |
| 64 | 参数错误/缺作者 | 补齐参数后运行 |
| 70 | 页面等待超时、跳转竞态或协议错误 | 批量停止，保留当前篇与已有暂停记录 |

## 批量与续跑

10 篇以上用批量驱动；较少篇目需要续跑和去重时也可用。

```bash
# 清单：题名|第一作者|目标文件夹；支持空行与 # 注释
python3 "$SK/cnki_batch.py" 清单.txt
python3 "$SK/cnki_batch.py" 清单.txt --expert "SU='学习进阶' AND SU='化学'" --pages 3
python3 "$SK/cnki_batch.py" 清单.txt --affiliation "机构名"
```

- 状态表 `<清单名>.状态.md` 给人阅读；旁边 `.progress.json` 保存文献身份与文件路径、大小、修改时间。重排/插入清单不影响已有身份，不再仅因某序号为 ✅ 就跳过。
- 每次跳过均核验实际文件。旧状态表无需删除；唯一的“归一化精确题名 + 作者”已有文件可导入进度，不能确认的条目重新核对。修改或缺失的已记录文件不当作有效完成。
- 同批次相同文献和目录只执行一次，失败的重复项也不连续重复请求。批量维持至少 2 秒的篇间节奏。
- 统一 `--expert` 使用 `.search-index.json`，同一检索式与页数的结果最多复用 24 小时，缓存命中仍核对实时详情。`--refresh-index` 重建。一般单篇不需要使用内部 `--index` 参数。
- 验证码出现后保存状态再暂停，并按[人工交接](cli.md#人工交接与调度约束)向用户提问、等待实际回复；先检查当前篇是否自动落盘，再记录恢复决定继续。无交互终端会退出 2，保留记录，不能将进程退出当成用户跳过。

手工维护状态表时，可用 `cnki_status.py "唯一题名片段" "✅" "已下载 路径" "下载状态.md"`。它支持状态在前和序号在前两种格式；批量流程已自动更新，无须再重复调用。

## 核验与排错

成功文件确认 PDF/CAJ 类型、题名作者与归档路径；PDF 页数用 `python3 "$SK/pdf_pages.py" "文件.pdf"` 辅助核验。排除 `._*`，CAJ 单独备注。汇报已有全文、本次新增、仅题录、失败/待人工数量与路径。

失败时才读 [troubleshooting-macos.md](troubleshooting-macos.md)，含专业检索、验证码、跨设备移动与页面诊断。不要提前加载全部排错和源码。
