# Playwright 扩展修复与验收记录

日期：2026-09-13。基于 `codex/cross-platform-browser` 的 `b2d2d9c` 开始修复；版本元数据保持 `2.0.0-beta.3.pubmed.1`，本次没有发布或改动 Beta 3 标签。初始故障及证据见[问题报告](playwright-extension-findings-20260913.md)。

**后续使用规则已调整：macOS 仅使用 Apple Events，不继续采用 Playwright。以下扩展试验和待验状态作为历史证据保留。Windows 查看器自动保存尚不能保证稳定，受阻时须询问仅题录或保留标签页、批量手动下载；当前指引见 [Skill](../SKILL.md)。**

## 已实现的改动

1. **完整性与缓存**：HTTP 下载按同一次响应核对状态、长度与实际接收字节；传输不足有界重试一次，失败保留临时文件及诊断。首次归档和续跑均检查 PDF 结构，安装 pypdf 时检查可解析性。损坏旧缓存返回待处理；实际回复后可重取，也可明确归档正确文件，原件不覆盖。SHA-256 继续用于复制与后续变更检查，不能代替完整性验证。
2. **知网尾部兼容**：真实复测发现，知网会在 PDF 的 EOF 后附加 `WebFastLoad` 和 `FileProperty` XML。程序识别这个完整、有限长度的明确格式，保留原始字节；不接受任意尾部数据或不完整 XML。此修正同时有离线与真实文件证据。
3. **连接及脱敏**：内部连接页不再算网页连接成功；同时读取网页地址和页面脚本结果。`browser connect --url` 明确新建任务标签，避免随意选取其他现有标签。连接参数及环境中的令牌值从诊断、输出和检查点中过滤。
4. **点击准备与事件**：只将绑定任务标签置前台；验证、Cookie 遮罩和控件试探失败时零下载点击。监听同一任务的弹出页及较早的上下文建页事件，忽略无关标签。仍保留下载目录检测，缺少事件不能再次点击。实际点击异常后也不会自动重放。
5. **PDF 阶段续跑**：已请求正文、PDF 已打开及保存阶段写入检查点。恢复先核验已有文件，再识别同篇当前页或其弹出页；不退回文章页或重复解析 DOI。实测发现 PDF 跳转后扩展可能回到连接欢迎页、PDF 丢失 opener 关联；此时只在已连接上下文中按检查点的同篇 PDF 链接找回唯一标签，歧义或选中后地址变化均暂停。不通过更换来源逃离验证。
6. **macOS 扩展保存**：新增扩展页面与 Chrome 原生窗口、标签和 PDF URL 的对应检查，随后复用既有受控保存逻辑。识别实测出现的 Playwright 标签组窗口标题，并要求原生窗口类型、位置和尺寸一致。无需为扩展启用 Apple Events JavaScript，但原生保存仍需 Chrome / System Events 自动化及辅助功能权限。Windows 保存窗口继续由测试者人工处理。
7. **核验状态与说明**：区分解析器缺失、解析失败、文字提取失败、缺少身份元数据和明确错篇。结果分别记录归档、正文身份核验及下载路线，不将解析失败等同于缺少可选依赖。

## 离线验证及支持边界

- 142 项离线用例：141 项通过，1 项隔离 Chrome 传输测试按配置跳过。
- 禁用 site-packages 后同一套 142 项仍通过上述检查，确认缺少可选 pypdf 时格式检查和状态契约仍能运行。
- 下载成功的离线夹具改为标准库生成的真实、带交叉引用表的 PDF，避免用仅有标头的伪文件证明归档正确。
- 新增覆盖截断响应、有界重试、无长度响应、分块中断、部分响应、CNKI 尾部、损坏缓存与人工替换、损坏旧文件不再重复采用、连接误判和令牌过滤、Cookie/后台零点击、控件试探失败、弹出页事件、旧检查点迁移、PDF 同篇恢复、丢失 opener 后的唯一标签恢复和原生窗口不匹配。
- 暂无 Windows 实机及其他 Harness 的新增验收。上下文建页监听已补齐，但本机知网事件仍缺失，可靠落盘来自目录恢复。不得声明官方扩展所有站点的下载事件已修复。
- Skill 元数据校验通过。两个平台测试包已核对 ZIP 完整性、SHA-256 和打包排除项，在中文及空格目录解压后，macOS 启动器与两包共享 Python 接口入口通过环境检查；Windows `.cmd` 仅做静态检查，不等于 Windows 实机运行通过。

原始结果、正文及校验清单位于本机 `tmp/playwright-repair-acceptance-20260913/`，其中 `verified-files.json` 保存各文件大小、SHA-256 和分层核验结果。令牌、论文与浏览器状态均不打入测试包。
